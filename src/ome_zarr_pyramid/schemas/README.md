# Vendored NGFF schemas

The JSON schemas of OME-NGFF 0.4, 0.5 and 0.6, unchanged, as published at
https://ngff.openmicroscopy.org/<version>/schemas/ (the files of the OME-NGFF
repository, https://github.com/ome/ngff). `ome_zarr_pyramid.validate` and the writers'
`validate=True` check stores against them (`ome_zarr_pyramid/core/validation.py`).

They are copyright the OME-NGFF contributors and are redistributed under the
[W3C Software and Document License](https://www.w3.org/Consortium/Legal/2015/copyright-software-and-document),
the license of the OME-NGFF repository's reports (https://github.com/ome/ngff/blob/main/LICENSE.md).
No changes were made to them.
